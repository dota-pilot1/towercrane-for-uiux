# Towercrane 메뉴 추가 방법

Towercrane의 헤더 메뉴는 **DB-driven** 구조입니다. 서버 부팅 시 `DatabaseService`가 메뉴 테이블을 upsert하므로, 새 메뉴를 추가하려면 **세 파일을 동시에 수정**해야 합니다.

---

## 수정해야 할 파일

| 파일 | 역할 |
|---|---|
| `towercrane-for-uiux-server/src/database/database.service.ts` | DB upsert — 서버 재시작 시 메뉴 생성 |
| `towercrane-for-uiux-front/src/widgets/app-header/ui/app-header.tsx` | sectionId ↔ 라우트 경로 매핑 |
| `towercrane-for-uiux-front/src/app/router.tsx` | 실제 페이지 라우트 등록 |

---

## 메뉴 종류

| 종류 | 설명 | parentId |
|---|---|---|
| **루트 메뉴** | 헤더에 직접 노출 | `null` |
| **자식 메뉴** | 루트 메뉴 드롭다운 항목 | 부모의 `id` |

---

## 1. database.service.ts — 루트 메뉴 추가

`ensureMenus` 메서드 안, 기존 upsert 블록들 뒤에 추가합니다.

```typescript
const existingMyMenu = this.sqlite
  .prepare("SELECT id FROM menus WHERE section_id = 'MY_SECTION' AND parent_id IS NULL LIMIT 1")
  .get() as { id: string } | undefined;

if (!existingMyMenu) {
  this.db.insert(menusTable).values({
    id: randomUUID(),
    name: '메뉴명',
    sectionId: 'my_section',
    icon: 'LucideIconName',   // PascalCase Lucide 아이콘
    displayOrder: 9,          // Admin 바로 앞이면 9번
    isVisible: true,
    requiredRole: null,       // admin 전용이면 'admin'
    parentId: null,
    createdAt: now,
    updatedAt: now,
  }).run();
}
```

### 자식 메뉴가 있을 경우

부모 메뉴 ID를 변수로 잡고, children 배열을 순회해 삽입합니다.

```typescript
if (!existingMyMenu) {
  const parentId = randomUUID();
  this.db.insert(menusTable).values({ id: parentId, ...루트메뉴 }).run();

  const children = [
    { name: '자식1', sectionId: 'child_1', icon: 'Star', displayOrder: 0 },
    { name: '자식2', sectionId: 'child_2', icon: 'Zap',  displayOrder: 1 },
  ];
  for (const child of children) {
    this.db.insert(menusTable).values({
      id: randomUUID(),
      ...child,
      isVisible: true,
      requiredRole: null,
      parentId,
      createdAt: now,
      updatedAt: now,
    }).run();
  }
}
```

### rootMenuOrder 배열 업데이트 (순서 고정)

파일 하단의 `rootMenuOrder` 배열에 새 메뉴를 원하는 위치로 추가합니다.

```typescript
const rootMenuOrder = [
  // ... 기존 항목들 ...
  { sectionId: 'my_section',    displayOrder: 9  },
  { sectionId: 'admin_dropdown', displayOrder: 10 }, // Admin은 항상 마지막
];
```

## 2. app-header.tsx — 라우팅 맵 등록

두 함수를 수정합니다.

### sectionIdToPath (클릭 시 이동 경로)

```typescript
const map: Record<string, string> = {
  // ... 기존 항목들 ...
  my_section: '/my-route',
  child_1: '/my-route/child1',
  child_2: '/my-route/child2',
}
```

### getSectionIdFromPath (현재 페이지 액티브 표시)

구체적인 경로를 먼저, 덜 구체적인 경로를 뒤에 배치해야 합니다.

```typescript
// ⚠️ 더 구체적인 경로가 위로
if (pathname.startsWith('/my-route/child1')) return 'child_1'
if (pathname.startsWith('/my-route/child2')) return 'child_2'
if (pathname.startsWith('/my-route')) return 'my_section'
```

## 3. router.tsx — 페이지 라우트 등록

```typescript
// 1) import 추가
import { MyPage } from '../pages/my-page/ui/my-page'

// 2) createRoute 추가
const myRoute = createRoute({
  getParentRoute: () => appLayoutRoute,
  path: '/my-route',
  component: MyPage,
})

// 3) appLayoutRoute.addChildren([...]) 배열에 추가
appLayoutRoute.addChildren([
  // ... 기존 라우트들 ...
  myRoute,
])
```

## 적용 절차 요약

1. `database.service.ts` upsert 블록 추가 + `rootMenuOrder` 업데이트
2. `app-header.tsx` `sectionIdToPath` 맵 + `getSectionIdFromPath` 분기 추가
3. `router.tsx` import + createRoute + addChildren 추가
4. 페이지 파일 생성 (`src/pages/xxx/ui/xxx-page.tsx`)
5. **서버 재시작** → DB upsert 실행됨
6. 브라우저에서 메뉴 확인

## 주의사항

- `sectionId`는 전역 고유값 — 기존 것과 절대 중복 금지
- `getSectionIdFromPath`에서 경로 순서 중요 — `/a/b`가 `/a`보다 앞에 와야 함
- DB upsert는 **서버 재시작 시**에만 실행됨 → 프론트만 수정해도 서버 재시작 필요
- 항상 **main 브랜치에서 직접 작업** (worktree 금지)
