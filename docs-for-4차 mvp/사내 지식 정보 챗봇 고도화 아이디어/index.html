현재 구현된 Level 1-2 지식검색 챗봇을 4차 MVP에서 더 실무형으로 끌어올리기 위한 우선순위 아이디어입니다. 초점은 답변 품질보다 먼저 사용 흐름, 검색 정확도, 운영 정책을 안정화하는 것입니다.

현재 달성 수준

Level 1

지식 문서 기반 응답

공지사항, FAQ, 개발 자료에 등록된 문서를 검색하고 GPT 답변에 참고 context로 전달하는 기본 루프가 구현되어 있습니다.

Level 2

오른쪽 패널에서 검색 근거, score, snippet, 원문 링크를 확인할 수 있어 사내 지식 시스템으로 설명 가능한 형태가 되었습니다.

우선순위 1. 지식 채널 선택을 왼쪽 사이드바로 이동

현재 지식 채널 선택은 챗봇 상단에 있으며 기능적으로는 충분하지만, 대화가 길어질수록 사용자가 “현재 어떤 지식 범위로 질문 중인지”를 놓치기 쉽습니다. 왼쪽 사이드바에 채널 선택을 배치하면 챗봇의 작동 범위가 항상 보이고, 대화 목록과 지식 범위를 함께 관리할 수 있습니다.

영역 역할 구현 방향
왼쪽 사이드바 대화 목록 + 지식 범위 선택 전체, 공지사항, FAQ, 개발 자료, AI 자료를 토글 또는 세그먼트로 제공
중앙 질문과 답변 상단 채널 버튼을 제거하고 대화 집중도를 높임
오른쪽 사이드바 검색 근거 확인 검색 결과, score, snippet, 원문 링크를 유지
1사용자가 왼쪽에서 검색 범위 선택
2질문 입력
3선택 범위로 chunk 검색
4GPT 답변 생성
5오른쪽에 근거 표시
지식 채널 등록/수정 화면까지 왼쪽에 넣는 것은 권장하지 않습니다. 왼쪽은 답변 범위 선택용, 상단 지식채널 메뉴는 문서 관리용으로 역할을 분리하는 편이 명확합니다.

우선순위 2. 검색 결과 score threshold 조정

현재 키워드 기반 chunk 검색은 등록 문서가 적을 때는 체감 정확도가 높지만, 문서 수가 늘어나면 질문과 약하게만 관련된 문서도 결과에 섞일 수 있습니다. score threshold를 두면 GPT에 넘기는 context를 더 보수적으로 제어할 수 있습니다.

항목 권장 정책 이유
최소 score minScore = 8~12부터 시작 관련성이 낮은 문서를 GPT context에서 제외
Top-K 3~5개 답변에 필요한 근거만 제한적으로 전달
강한 매칭 가중치 제목, 태그, 질문 필드에 더 높은 점수 본문 전체보다 사용자가 붙인 구조화 정보가 더 의도에 가까움
낮은 score 처리 근거 없음 메시지 또는 일반 답변 모드로 전환 관련 없는 문서를 근거처럼 보여주는 문제 방지
threshold는 너무 높게 시작하면 “검색 결과 없음”이 자주 발생합니다. 운영 초반에는 결과를 오른쪽 패널에 노출하면서 score 분포를 보고 조정하는 방식이 적절합니다.

우선순위 3. 문서 만료일/게시 상태 기준으로 검색 제외 처리

사내 지식 시스템에서는 오래된 공지나 임시 저장 문서가 답변에 섞이면 신뢰도가 크게 떨어집니다. 검색 단계에서 게시 상태와 만료일을 먼저 필터링해야 합니다.

조건 검색 포함 여부 비고
status = published 포함 챗봇 답변 대상의 기본 조건
status = draft 제외 작성 중 문서가 사용자 답변에 노출되지 않도록 처리
publishedAt > now 제외 예약 게시 문서 보호
expiresAt < now 제외 만료 공지가 답변에 반영되지 않도록 처리
visibility 제한 권한에 따라 포함 4차 이후 권한별 검색으로 확장 가능
배치로 만료 문서를 자동 off 처리하는 것도 가능하지만, 우선은 검색 query에서 만료 문서를 제외하는 방식이 더 단순하고 안정적입니다. 이후 운영 화면에서 “만료됨” 상태를 별도 표시하면 됩니다.

구현 순서 제안

  1. 검색 정책 먼저 정리: published, expiresAt, minScore, limit 기준을 백엔드 search 서비스에 반영합니다.
  2. 오른쪽 근거 패널에 threshold 결과 표시: 제외된 결과를 보여줄 필요는 없지만, 검색 결과가 없을 때는 “선택한 범위에서 충분한 근거를 찾지 못했습니다” 메시지를 제공합니다.
  3. 왼쪽 사이드바 UX 개편: 현재 상단 채널 버튼을 왼쪽으로 옮기고, 대화 목록과 충돌하지 않게 접힘/섹션 구조를 잡습니다.

완료 기준

기능 기준

  • 왼쪽에서 선택한 채널 범위가 질문 전후로 유지된다.
  • 낮은 score 문서는 GPT context에 들어가지 않는다.
  • 임시저장, 예약 게시, 만료 문서는 검색되지 않는다.
  • 검색 결과가 없을 때 답변이 과장되지 않는다.

시연 기준

  • 공지사항만 선택하면 FAQ/개발 자료가 제외된다.
  • 개발 자료만 선택하면 디자인 시스템 문서가 우선 검색된다.
  • 오른쪽 근거 패널에서 원문 링크로 관리 화면 이동이 가능하다.
  • 만료일이 지난 공지는 답변 근거에 나타나지 않는다.
