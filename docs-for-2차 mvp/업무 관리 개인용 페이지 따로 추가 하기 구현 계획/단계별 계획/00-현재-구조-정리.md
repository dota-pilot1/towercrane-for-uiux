## 백엔드

### `/Users/terecal/towercrane-for-uiux/towercrane-for-uiux-server/src/database/schema.ts`

- `usersTable`이 사용자 기준 데이터의 기준이다.
- `tasksTable`은 현재 `reporterId`, `assigneeId`, `archived`, `orderIdx`를 갖고 있다.

## 핵심 판단

- 전체 업무와 개인 업무를 별도 테이블로 나누지 않는다.
- 업무 엔티티는 하나로 유지하고 `scope`, `ownerId`, `visibility`, query scope로 구분한다.
- 현재 UI 컴포넌트 재사용 비율이 높아지고, 댓글/첨부/체크리스트 기능도 중복 구현하지 않는다.
