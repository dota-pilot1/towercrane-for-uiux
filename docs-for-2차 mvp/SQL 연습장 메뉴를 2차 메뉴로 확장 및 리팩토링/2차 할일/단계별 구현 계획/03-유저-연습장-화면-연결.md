# 3단계 - 유저 연습장 화면 연결

## 목표

`/sql/user` 화면을 실제 유저 문제 풀이 화면으로 연결한다.

공식 연습장 UI를 최대한 재사용하되, 데이터 소스는 유저 문제 API로 바꾼다.

## 화면 구조

```text
상단 헤더
- SQL 연습장(유저)
- 문제 만들기

왼쪽 사이드바
- 문제 목록
- Level 1~5 필터
- 전체 문제 / 내가 만든 문제

중앙
- 문제 설명
- SQL 입력
- 실행 결과
- 제출 결과

오른쪽 사이드바
- 커머스 DB 정보
- 테이블 목록
- 테이블 상세
- ERD 보기
```

## 구현 기준

- 공식 연습장의 실행 결과 테이블, SQL 입력창, 테이블 사이드바 컴포넌트를 재사용한다.
- 문제 목록 컴포넌트는 유저 문제 데이터 구조에 맞게 별도 분리한다.
- 아직 문제가 없을 때는 빈 상태와 문제 만들기 CTA를 보여준다.

## 완료 기준

- `/sql/user`에서 유저 문제 목록이 보인다.
- 문제 선택 시 중앙에 문제 설명과 SQL 입력창이 보인다.
- 오른쪽 사이드바에서 커머스 DB 테이블이 보인다.
