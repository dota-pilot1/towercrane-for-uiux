# 4단계 - 문제 출제 UI

## 목표

유저가 직접 문제를 만들 수 있는 작성 화면을 제공한다.

## 작성 방식

문제 추가는 왼쪽 사이드바 안에서 처리하지 않는다. 중앙 패널 또는 다이얼로그에서 충분한 입력 공간을 제공한다.

## 입력 항목

```text
제목
설명
난이도 Level 1~5
관련 테이블
시작 SQL
정답 SQL
해설
공개 여부
```

## UX 기준

- 관련 테이블은 오른쪽 사이드바의 테이블 목록과 연결한다.
- 난이도는 숫자 레벨로 선택한다.
- 정답 SQL은 작성 중 실행해볼 수 있어야 한다.
- 공개 전에는 draft 상태로 저장할 수 있어야 한다.

## 완료 기준

- 문제 작성 후 목록에 즉시 반영된다.
- 내가 만든 문제는 수정/삭제할 수 있다.
- 공개 문제는 다른 유저의 목록에도 보인다.
