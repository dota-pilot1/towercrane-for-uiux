# 5단계 - 제출과 채점

## 목표

유저가 문제에 대한 SQL을 제출하고, 결과를 저장한다.

## MVP 채점 방식

초기에는 정답 SQL과 제출 SQL의 결과 집합을 비교한다.

```text
정답 SQL 실행 결과
제출 SQL 실행 결과
→ 컬럼과 row를 정규화해서 비교
```

## 주의점

- row 순서가 중요한 문제와 중요하지 않은 문제를 구분해야 한다.
- `SELECT *`처럼 컬럼 순서가 달라질 수 있는 쿼리는 비교 정책을 정해야 한다.
- 실행 시간 제한과 row 제한을 둔다.
- DDL/DML은 제출용 문제에서는 기본적으로 막는다.

## 제출 데이터

```text
sql_user_practice_submissions
- id
- problem_id
- user_id
- submitted_sql
- is_correct
- score
- feedback
- created_at
```

## 완료 기준

- 제출 기록이 저장된다.
- 정답/오답 결과가 표시된다.
- 내 제출 이력을 확인할 수 있다.
