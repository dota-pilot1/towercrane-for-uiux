```bash
cd towercrane-for-uiux-server
npm run build

cd ../towercrane-for-uiux-front
npm run build
```

## 기능 검증

1. `/sql/personal` 진입
2. 오른쪽 테이블 패널에서 `SQL 교체` 버튼 확인
3. 버튼이 `ERD` 왼쪽에 있는지 확인
4. 버튼 높이가 `ERD`와 같은지 확인
5. `.txt` 업로드 시 클라이언트/서버에서 거부
6. 문법 오류 있는 `.sql` 업로드 시 실패
7. 정상 `.sql` 업로드 시 성공
8. schema version이 `v2`로 변경
9. 오른쪽 테이블 목록이 새 SQL 기준으로 변경
10. 테이블 클릭 시 새 DB 기준 row data 표시
11. 새 문제 생성 시 `schemaVersionId = v2`

## 보존 검증

1. v1 상태에서 문제 A 생성
2. 문제 A 공유 링크 생성
3. SQL 파일 교체로 v2 생성
4. v2 상태에서 문제 B 생성
5. 문제 A는 v1 기준으로 채점되는지 확인
6. 문제 A 공유 링크도 v1 기준으로 동작하는지 확인
7. 문제 B는 v2 기준으로 채점되는지 확인

## API 검증

정상 업로드:

```bash
curl -X POST \
  -H "Authorization: Bearer <token>" \
  -F "file=@/path/to/new_schema.sql" \
  -F "title=새 개인 DB" \
  http://127.0.0.1:3000/api/sql/personal/workspaces/<workspaceId>/schema-versions/replace
```

기대:

- `schemaVersion.version` 증가
- `tableCount > 0`
- `tables` 배열 반환

## 회귀 검증

- `/sql/user` 기존 풀이 UI 정상
- `/sql/user`에는 `SQL 교체` 버튼 없음
- `/share/sql/personal/:token` 공개 풀이 정상
- 공개 풀이에는 `SQL 교체` 버튼 없음
- 기존 테이블 상세 모달 데이터 조회 정상
