# 01. 백엔드 업로드 엔드포인트

## 목표

개인 workspace 소유자만 `.sql` 파일을 업로드해 새 schema version을 만들 수 있는 API를 추가한다.

## 대상 파일

```text
towercrane-for-uiux-server/src/sql-practice/sql-practice.controller.ts
towercrane-for-uiux-server/src/sql-practice/sql-practice.schemas.ts
towercrane-for-uiux-server/src/sql-practice/sql-practice.types.ts
```

## API

```text
POST /api/sql/personal/workspaces/:workspaceId/schema-versions/replace
Content-Type: multipart/form-data

file: File (.sql)
title?: string
description?: string
```

## controller 계획

`SqlPracticeController`에 추가한다.

```ts
@Post('personal/workspaces/:workspaceId/schema-versions/replace')
@UseInterceptors(FileInterceptor('file'))
replacePersonalSchemaVersion(
  @Param('workspaceId') workspaceId: string,
  @UploadedFile() file: Express.Multer.File,
  @Body() body: unknown,
  @Req() req: SessionRequest,
) {
  const input = replacePersonalSchemaVersionSchema.parse(body);
  return this.sqlPracticeService.replacePersonalPracticeSchemaVersion(
    workspaceId,
    file,
    input,
    req.user.id,
  );
}
```

## schema 계획

`sql-practice.schemas.ts`에 추가한다.

```ts
export const replacePersonalSchemaVersionSchema = z.object({
  title: z.string().trim().max(80).optional(),
  description: z.string().trim().max(500).optional(),
});
```

파일 자체는 zod가 아니라 multer/service에서 검증한다.

## types 계획

`sql-practice.types.ts`에 추가한다.

```ts
export type SqlPersonalPracticeSchemaReplaceResponse = {
  workspace: SqlPersonalPracticeWorkspace;
  schemaVersion: SqlPersonalPracticeSchemaVersion;
  tableCount: number;
  tables: TableInfo[];
};
```

## 주의점

- 공개 공유 controller에는 업로드 endpoint를 만들지 않는다.
- `/sql/user`에는 업로드 endpoint를 만들지 않는다.
- 반드시 `assertPersonalWorkspaceOwner`로 소유자 권한을 검증한다.
- 파일 미첨부는 `BadRequestException`으로 처리한다.
