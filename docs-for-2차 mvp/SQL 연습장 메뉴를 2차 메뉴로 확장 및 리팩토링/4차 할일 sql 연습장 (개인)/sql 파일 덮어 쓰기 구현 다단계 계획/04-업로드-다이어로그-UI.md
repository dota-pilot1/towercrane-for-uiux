# 04. 업로드 다이어로그 UI

## 목표

`SQL 교체` 버튼 클릭 시 열리는 업로드 다이어로그를 만든다.

## 신규 파일

```text
towercrane-for-uiux-front/src/pages/sql-practice/ui/sql-personal-schema-replace-dialog.tsx
```

## props

```ts
type SqlPersonalSchemaReplaceDialogProps = {
  open: boolean
  workspaceTitle: string
  currentVersion?: SqlPersonalPracticeSchemaVersion
  isPending: boolean
  errorMessage?: string | null
  onSubmit: (input: {
    file: File
    title?: string
    description?: string
  }) => Promise<void>
  onClose: () => void
}
```

## UI 구성

상단:

- 제목: `SQL 파일 교체`
- 설명: `새 schema version을 만들고 개인 연습장의 active DB를 변경합니다.`

현재 버전 정보:

- workspace title
- 현재 version
- 현재 hash
- source file name

입력:

- `.sql` file input
- title input
- description textarea

경고 박스:

```text
기존 문제와 공유 링크는 기존 DB 기준으로 유지됩니다.
교체 후 새로 만드는 문제부터 업로드한 SQL 기준으로 생성됩니다.
```

버튼:

- 취소
- 교체하기

## 클라이언트 검증

교체하기 버튼 disabled 조건:

- file 없음
- file 확장자가 `.sql` 아님
- mutation pending

파일 선택 시:

- 파일명 표시
- 파일 크기 표시
- `.sql`이 아니면 inline error 표시

## 스타일 규칙

AGENTS.md 규칙을 지킨다.

금지:

- `text-white`
- `text-slate-*`
- `bg-white/*`
- `bg-slate-*`
- `text-emerald-*`

사용:

- `text-text-primary`
- `text-text-secondary`
- `text-text-muted`
- `bg-surface-muted`
- `bg-surface-raised`
- `border-surface-border-soft`
- `bg-brand-glass`
- `border-brand-border`

## 성공 후 처리

submit 성공은 parent에서 처리한다.

다이어로그는:

- pending 표시
- error 표시
- 성공 시 parent가 닫음
