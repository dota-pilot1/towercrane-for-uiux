# 00. 현재 구조 정리

## 프론트엔드

### `towercrane-for-uiux-front/src/app/router.tsx`

현재 상태:

- `/sql/user`는 `SqlUserPracticePage mode="user"`로 연결되어 있다.
- `/sql/personal`도 이미 라우트가 있지만 `SqlUserPracticePage mode="personal"`로 placeholder만 렌더링한다.
- `/share/sql-notes/$token` 공개 라우트는 rootRoute 하위에 있고 AppLayout auth guard 밖에 있다.

개인 연습장 구현 시 변경:

- `/sql/personal`은 기본 개인 workspace로 진입한다.
- `/sql/personal/workspaces/$workspaceId` 라우트를 추가해 workspace별 문제 관리 화면으로 연결한다.
- `/sql/personal/workspaces/$workspaceId/files`는 파일 교체 단계에서 추가한다.
- `/share/sql/personal/$token` 공개 라우트를 rootRoute 하위에 추가한다.
- 공개 공유 페이지는 AppHeader/AppLayout 없이 독립 화면으로 둔다.

### `towercrane-for-uiux-front/src/pages/sql-practice/ui/sql-user-practice-page.tsx`

현재 상태:

- `mode === 'personal'`이면 `SqlPersonalPracticePlaceholder`만 반환한다.
- 유저 문제 목록, 문제 등록 폼, 대상 테이블, SQL 입력, 실행 결과, 채점 다이얼로그가 한 파일에 함께 있다.
- 문제 등록 버튼이 항상 보인다.
- `useSqlUserPracticeProblems`, `useCreateSqlUserPracticeProblem`, `useGradeSqlUserPracticeProblem` 등 user 전용 query hook을 직접 사용한다.

개인 연습장 구현 시 변경:

- 공용으로 쓸 수 있는 문제 풀이 workspace 컴포넌트와 user/personal 전용 컨테이너를 분리한다.
- 개인 페이지는 `sql_personal_practice_*` API를 사용한다.
- 개인 문제는 active schema version에 묶어 생성한다.
- 기존 `/sql/user` 동작은 깨지지 않게 유지한다.

### `towercrane-for-uiux-front/src/entities/sql-practice/api/sql-practice-api.ts`

현재 상태:

- `/sql/user/*` API만 있다.
- 공개 API는 `/public/sql/notes/:token`만 있다.

개인 연습장 구현 시 변경:

- `/sql/personal/workspaces/*` 인증 API를 추가한다.
- `/public/sql/personal/:token` 공개 조회/채점 API를 추가한다.
- 파일 교체 단계에서는 `/sql/personal/workspaces/:workspaceId/schema-versions` API를 추가한다.

### `towercrane-for-uiux-front/src/features/sql-practice/model/use-sql-practice-queries.ts`

현재 상태:

- query key가 `userMeta`, `userTables`, `userProblems`, `userSubmissions` 중심이다.

개인 연습장 구현 시 변경:

- `personalWorkspaces`, `personalDefaultWorkspace`, `personalWorkspaceMeta`, `personalTables`, `personalProblems`, `personalProblem`, `publicPersonalProblem` query key를 추가한다.
- 생성/수정/삭제/공유 mutation 성공 시 workspace 단위 개인 문제 목록을 invalidate한다.

### `towercrane-for-uiux-front/src/widgets/app-header/ui/app-header.tsx`

현재 상태:

- `sql_personal` section id가 `/sql/personal`에 이미 매핑되어 있다.
- pathname이 `/sql/personal`로 시작하면 `sql_personal`이 active 된다.

개인 연습장 구현 시 변경:

- 메뉴 매핑은 유지한다.
- 공유 공개 페이지는 AppHeader 밖이므로 header 변경은 최소화한다.

## 백엔드

### `towercrane-for-uiux-server/src/sql-practice/sql-practice.controller.ts`

현재 상태:

- `@Controller('sql')` 전체가 `@UseGuards(AuthGuard)` 아래에 있다.
- `/sql/user/*` 인증 API가 구현되어 있다.
- `SqlPracticePublicController`에는 공개 노트 조회만 있다.

개인 연습장 구현 시 변경:

- 인증 API: `/sql/personal/workspaces/*`
- 공개 API: `/public/sql/personal/:token`, `/public/sql/personal/:token/grade`
- 공개 controller는 AuthGuard 밖에 둔다.

### `towercrane-for-uiux-server/src/sql-practice/sql-practice.service.ts`

현재 상태:

- `listUserPracticeProblems`
- `getUserPracticeProblem`
- `createUserPracticeProblem`
- `updateUserPracticeProblem`
- `deleteUserPracticeProblem`
- `generateUserPracticeAnswer`
- `gradeUserPracticeProblem`
- `getMyUserPracticeSubmissions`

개인 연습장 구현 시 변경:

- 개인 workspace 자동 생성 메서드를 추가한다.
- 개인 schema version별 runtime DB 생성/조회 메서드를 추가한다.
- 개인 문제는 owner + workspace + schema version 검증을 강제한다.
- 공유 token 발급/해제/공개 조회/공개 채점 메서드를 추가한다.

### `towercrane-for-uiux-server/src/database/schema.ts`

현재 상태:

- `sqlUserPracticeProblemsTable`에 `visibility`, `status`, `createdBy`가 있다.
- 개인 문제와 유저 문제를 구분하는 별도 도메인은 없다.
- 공유 token 컬럼이 없다.

개인 연습장 구현 시 변경:

- `sql_personal_practice_workspaces`
- `sql_personal_practice_schema_versions`
- `sql_personal_practice_problems`
- `sql_personal_practice_shares`

기존 `sql_user_practice_problems`에는 개인용 컬럼을 추가하지 않는다.

### `towercrane-for-uiux-server/src/database/database.service.ts`

현재 상태:

- 앱 시작 시 필요한 테이블과 일부 컬럼을 보강하는 SQL이 들어 있다.
- `sql_user_practice_problems` 생성 SQL이 있다.

개인 연습장 구현 시 변경:

- 신규 개인 연습장 테이블 4개와 인덱스를 생성한다.
- 기존 DB를 위한 `CREATE TABLE IF NOT EXISTS` 기반 보강 로직을 추가한다.
- 파일 교체 단계에서 schema version 업로드/활성화에 필요한 컬럼은 1차부터 포함한다.
