# 04. 프론트 UI 공통화와 개인 페이지 계획

## 목표

`/sql/user`와 `/sql/personal/workspaces/:workspaceId`가 같은 화면 구조를 공유하되, 데이터 소스와 액션만 다르게 만든다.

## 변경 파일

### `towercrane-for-uiux-front/src/pages/sql-practice/ui/sql-user-practice-page.tsx`

현재 한 파일에 몰려 있는 구현을 다음처럼 정리한다.

1. `/sql/user`용 컨테이너는 유지한다.
2. `SqlPersonalPracticePlaceholder`를 제거한다.
3. 개인 페이지는 별도 `SqlPersonalPracticePage`와 `SqlPersonalWorkspacePage`로 분리한다.

권장 구조:

```tsx
export function SqlUserPracticePage({ mode }: SqlUserPracticePageProps) {
  return <SqlUserPracticeWorkspace />
}
```

단, 파일이 너무 커지므로 공통 컴포넌트 분리를 먼저 진행한다.

### 신규 파일: `towercrane-for-uiux-front/src/features/sql-practice/ui/sql-user-practice-workspace.tsx`

기존 `SqlUserPracticeWorkspace`의 UI 대부분을 옮긴다.

props 예시:

```ts
type SqlPracticeProblemWorkspaceProps = {
  title: string
  schemaLabel: string
  canCreateProblem: boolean
  canManageSelectedProblem: (problem) => boolean
  problemsQuery: ...
  submissionsQuery?: ...
  createProblemMutation?: ...
  generateAnswerMutation?: ...
  gradeProblemMutation: ...
  onShareProblem?: (problemId: string) => void
  onUnshareProblem?: (problemId: string) => void
}
```

너무 범용화하면 복잡해지므로 첫 구현에서는 다음 단위만 분리한다.

- `ProblemListPanel`
- `ProblemForm`
- `ProblemDetailPanel`
- `SqlAnswerPanel`
- `SchemaPanel`
- `SqlUserPracticeGradeDialog`

### 신규 파일: `towercrane-for-uiux-front/src/pages/sql-practice/ui/sql-personal-practice-page.tsx`

개인 페이지 전용 컨테이너를 만든다. `/sql/personal`은 기본 workspace를 조회한 뒤 `/sql/personal/workspaces/:workspaceId`로 이동하거나, 기본 workspace 내용을 바로 렌더링한다.

역할:

- `useSqlPersonalPracticeProblems`
- `useSqlPersonalDefaultWorkspace`
- `useSqlPersonalWorkspaceMeta`
- `useSqlPersonalPracticeTables`
- `useCreateSqlPersonalPracticeProblem`
- `useUpdateSqlPersonalPracticeProblem`
- `useDeleteSqlPersonalPracticeProblem`
- `useShareSqlPersonalPracticeProblem`
- `useUnshareSqlPersonalPracticeProblem`
- `useGradeSqlPersonalPracticeProblem`

화면 차이:

- 헤더 제목: `SQL 연습장(개인)`
- 설명: `내 개인 DB 파일 기준으로 문제를 만들고 링크로 공유합니다.`
- active schema version 표시: `v1 · seed · hash abc123`
- 목록 필터: level + 공유 상태 필터
- `내가 만든 문제만` 체크박스는 제거한다. 개인 페이지는 항상 내 문제만 표시된다.
- 문제 카드에 공유 상태 표시:
  - 공유 중: `공유됨`
  - 미공유: `비공유`
- 문제 상세 우측 상단에 액션:
  - 공유 링크 만들기
  - 링크 복사
  - 공유 해제
  - 수정
  - 삭제
- 공유된 문제 카드/상세 영역에는 공개 URL을 짧게 표시하고, URL 옆에 `복사` 아이콘 버튼을 둔다.
- 아직 공유 token이 없는데 `링크 복사`를 누르면 먼저 share API를 호출해 token을 만든 뒤 URL을 복사한다.
- 이후 파일 교체 단계에서 `파일 관리` 버튼을 추가해 `/sql/personal/workspaces/:workspaceId/files`로 이동한다.

스타일 규칙:

- `text-white`, `text-slate-*`, `bg-white/*`, `border-white/*` 사용 금지
- 기존 파일처럼 `text-text-primary`, `text-text-muted`, `bg-surface-muted`, `border-surface-border-soft`, `ui-icon-button` 사용

### `towercrane-for-uiux-front/src/app/router.tsx`

`SqlPersonalPracticePage` import 추가:

```ts
import { SqlPersonalPracticePage } from '../pages/sql-practice/ui/sql-personal-practice-page'
```

라우트 변경:

```tsx
const sqlPersonalPracticeRoute = createRoute({
  getParentRoute: () => appLayoutRoute,
  path: '/sql/personal',
  component: SqlPersonalPracticePage,
})

const sqlPersonalWorkspaceRoute = createRoute({
  getParentRoute: () => appLayoutRoute,
  path: '/sql/personal/workspaces/$workspaceId',
  component: SqlPersonalWorkspacePage,
})
```

공유 페이지는 05 단계에서 별도 추가한다.

## 개인 페이지 UX 흐름

```text
1. 사용자가 /sql/personal 진입
2. 기본 개인 workspace 자동 생성/조회
3. active schema version 기준 테이블/문제 목록 조회
4. + 버튼으로 문제 등록 폼 열기
5. 문제 설명/테이블/정답 SQL 입력
6. 저장 시 active schema version에 문제 연결
7. 문제 선택
8. 공유 버튼 클릭
9. 링크 복사
10. 다른 사용자는 공유 페이지에서 해당 schema version 기준으로 풀이
```

## 수정/삭제 MVP 범위

MVP에서 최소 구현:

- 등록
- 삭제
- 공유/공유 해제
- 풀이/채점

수정은 API가 어렵지 않으므로 가능하면 포함한다. 시간이 부족하면 “등록 후 삭제 재생성”으로 MVP를 먼저 닫고, 수정은 다음 단계로 뺀다.
