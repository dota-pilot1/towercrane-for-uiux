# 문제 설명에 맞게 정답 SQL 생성 구현

## 목표

`SQL 연습장(유저)` 문제 등록 폼에서 문제 제목, 문제 설명, 관련 테이블을 입력한 뒤 `정답 SQL` 영역 우상단의 AI 버튼을 누르면 정답 SQL 초안을 생성한다.

## 구현 방향

- 기존 SQL AI 기능과 동일하게 서버에서 `Groq`를 호출한다.
- 프론트에서 Groq API Key를 직접 다루지 않는다.
- 서버는 생성된 SQL을 유저 연습장 sqlite DB에서 실행 검증한다.
- 검증 가능한 `SELECT/WITH` SQL만 프론트에 반환한다.

## UX

```text
정답 SQL
[AI 정답 생성 버튼]
[textarea]
```

- 버튼 위치: `정답 SQL` 입력 라벨 우측 상단
- 입력 조건: 제목 또는 문제 설명이 있어야 실행
- 생성 성공: 정답 SQL textarea에 자동 입력
- 생성 실패: toast로 오류 표시

## 요청 데이터

```text
title
description
level
targetTables
```

## 응답 데이터

```text
answerSql
explanation
```

`explanation`이 비어 있으면 기존 해설 입력값은 건드리지 않는다.

## 검증 정책

- 생성 결과는 SQL 코드만 추출한다.
- `SELECT` 또는 `WITH` 조회 쿼리만 허용한다.
- 서버에서 실제 유저 연습장 DB에 실행해보고 실패하면 오류로 반환한다.
- `INSERT`, `UPDATE`, `DELETE`, `CREATE`, `DROP`, `ALTER`는 정답 생성 결과로 허용하지 않는다.

## 이후 확장

- 생성된 SQL을 바로 결과 미리보기
- 난이도에 맞는 문제 설명 자동 보강
- 해설 자동 생성 품질 개선
- 정답 SQL 여러 후보 생성
