## 1. 게시판 설정 화면

경로: `/admin/board-configs`

참고: RestaurantBook의 `BoardConfigManager.tsx`

구성:

- 좌측 또는 상단: 게시판 설정 목록
- 우측: 추가/수정 폼
- 필드:
  - code
  - name
  - kind
  - description
  - orderIdx
  - allowUserWrite
  - allowComment
  - isActive

동작:

- 신규 생성
- 수정
- 비활성화
- code 중복 에러 표시
- `notice`, `inquiry`는 code 변경 불가

UI 원칙:

- 폼 입력은 `shared/ui/input.tsx`, `textarea.tsx`, `select.tsx`, `switch.tsx` 재사용
- 버튼은 `shared/ui/button.tsx`, 아이콘 버튼은 `ui-icon-button` 계열 사용
- raw Tailwind 색상 금지

## 2. 게시글 관리 화면

경로: `/admin/boards`

참고: RestaurantBook의 `AdminBoardManagement.tsx`

구성:

```txt
┌──────────────────────────────────────────────────────┐
│ 상단: 제목, 미답변 문의 count, 새 글 버튼             │
├───────────────┬────────────────────┬─────────────────┤
│ 게시판 목록    │ 게시글 테이블        │ 상세/답변 패널    │
└───────────────┴────────────────────┴─────────────────┘
```

왼쪽 게시판 목록:

- 전체 활성/비활성 게시판
- 문의 게시판에는 미답변 배지
- 비활성 게시판은 muted 스타일

중앙 게시글 테이블:

- 핀 여부
- 상태
- 제목
- 작성자
- 답변 여부
- 조회수
- 작성일
- 액션: 수정, 숨김/게시, 핀/해제, 삭제

오른쪽 상세/답변 패널:

- 게시글 내용
- 댓글/답변 목록
- 관리자 답변 작성
- 문의글 답변 성공 시 `answered=true`

## 4. 관리자 query hook

`features/board-admin/model/use-admin-board-queries.ts`

query key:

```ts
export const adminBoardQueryKeys = {
  all: ['adminBoards'] as const,
  configs: () => ['adminBoards', 'configs'] as const,
  list: (code: string, filters: BoardFilters) => ['adminBoards', 'list', code, filters] as const,
  unansweredCount: () => ['adminBoards', 'unansweredCount'] as const,
}
```

mutation 성공 시:

- config 변경: configs + 사용자 configs invalidate
- 게시글 변경: admin list + 사용자 list/detail invalidate
- 답변 변경: unansweredCount + list/detail/comments invalidate

## 5. `app/router.tsx` 관리자 라우트

추가:

```ts
import { AdminBoardConfigPage } from '../pages/board-admin/ui/admin-board-config-page'
import { AdminBoardManagementPage } from '../pages/board-admin/ui/admin-board-management-page'
```

```ts
const adminBoardConfigsRoute = createRoute({
  getParentRoute: () => appLayoutRoute,
  path: '/admin/board-configs',
  component: AdminBoardConfigPage,
})

const adminBoardsRoute = createRoute({
  getParentRoute: () => appLayoutRoute,
  path: '/admin/boards',
  component: AdminBoardManagementPage,
})
```

관리자 접근 제어는 서버가 최종 담당한다. 프론트에서는 일반 사용자에게 메뉴가 안 보이게 하고, 직접 진입 시 403 토스트/대체 화면을 보여준다.

## 6. 화면 검증

- 관리자 계정으로 `/admin/board-configs` 진입
- `event` 게시판 생성
- 사용자 `/boards`에 `event` 카드 표시
- `event` 비활성화 후 사용자 목록에서 제거
- `/admin/boards`에서 `notice` 선택 후 공지 작성
- `/boards/notice`에 공지 표시
- 일반 사용자가 `/boards/inquiry`에 문의 작성
- `/admin/boards` 미답변 카운트 증가
- 관리자 답변 등록 후 미답변 카운트 감소
- 모바일 폭에서 테이블은 카드형 또는 가로 스크롤로 깨지지 않게 처리
