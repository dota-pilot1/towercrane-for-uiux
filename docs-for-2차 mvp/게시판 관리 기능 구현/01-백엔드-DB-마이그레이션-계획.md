# 01. 백엔드 DB / 마이그레이션 계획

## 목표

`board_configs`, `boards`, `board_comments` 테이블을 추가하고, `notice`, `inquiry` 기본 게시판을 idempotent seed로 넣는다.

## 수정 파일

### 1. `towercrane-for-uiux-server/src/database/schema.ts`

추가 타입:

```ts
export type BoardKind = 'NOTICE' | 'INQUIRY' | 'FAQ' | 'EVENT' | 'GENERAL'
export type BoardStatus = 'PUBLISHED' | 'HIDDEN' | 'DRAFT'
```

추가 테이블:

- `boardConfigsTable`
- `boardsTable`
- `boardCommentsTable`

권장 컬럼:

```ts
export const boardConfigsTable = sqliteTable('board_configs', {
  id: text('id').primaryKey(),
  code: text('code').notNull().unique(),
  kind: text('kind').$type<BoardKind>().notNull(),
  name: text('name').notNull(),
  description: text('description'),
  allowUserWrite: integer('allow_user_write', { mode: 'boolean' }).notNull().default(false),
  allowComment: integer('allow_comment', { mode: 'boolean' }).notNull().default(false),
  isActive: integer('is_active', { mode: 'boolean' }).notNull().default(true),
  orderIdx: integer('order_idx').notNull().default(0),
  createdAt: text('created_at').notNull(),
  updatedAt: text('updated_at').notNull(),
})
```

```ts
export const boardsTable = sqliteTable('boards', {
  id: text('id').primaryKey(),
  boardConfigId: text('board_config_id').notNull().references(() => boardConfigsTable.id, { onDelete: 'cascade' }),
  authorId: text('author_id').references(() => usersTable.id, { onDelete: 'set null' }),
  authorName: text('author_name').notNull(),
  title: text('title').notNull(),
  content: text('content').notNull().default(''),
  status: text('status').$type<BoardStatus>().notNull().default('PUBLISHED'),
  pinned: integer('pinned', { mode: 'boolean' }).notNull().default(false),
  pinnedOrder: integer('pinned_order'),
  answered: integer('answered', { mode: 'boolean' }).notNull().default(false),
  viewCount: integer('view_count').notNull().default(0),
  deletedAt: text('deleted_at'),
  createdAt: text('created_at').notNull(),
  updatedAt: text('updated_at').notNull(),
})
```

```ts
export const boardCommentsTable = sqliteTable('board_comments', {
  id: text('id').primaryKey(),
  boardId: text('board_id').notNull().references(() => boardsTable.id, { onDelete: 'cascade' }),
  authorId: text('author_id').references(() => usersTable.id, { onDelete: 'set null' }),
  authorName: text('author_name').notNull(),
  content: text('content').notNull(),
  adminReply: integer('admin_reply', { mode: 'boolean' }).notNull().default(false),
  deleted: integer('deleted', { mode: 'boolean' }).notNull().default(false),
  createdAt: text('created_at').notNull(),
  updatedAt: text('updated_at').notNull(),
})
```

마지막 `schema` export에 세 테이블을 포함한다.

### 2. `towercrane-for-uiux-server/src/database/database.service.ts`

`onModuleInit()`의 SQL 블록에 `CREATE TABLE IF NOT EXISTS`와 인덱스를 추가한다.

필수 인덱스:

```sql
CREATE INDEX IF NOT EXISTS idx_board_configs_active_order
  ON board_configs(is_active, order_idx);

CREATE INDEX IF NOT EXISTS idx_boards_config_status_deleted
  ON boards(board_config_id, status, deleted_at);

CREATE INDEX IF NOT EXISTS idx_boards_pinned_order
  ON boards(board_config_id, pinned, pinned_order, created_at);

CREATE INDEX IF NOT EXISTS idx_board_comments_board_deleted
  ON board_comments(board_id, deleted);
```

seed 함수 또는 `onModuleInit()` 하단에 기본 게시판 upsert를 추가한다.

```sql
INSERT INTO board_configs (
  id, code, kind, name, description, allow_user_write, allow_comment,
  is_active, order_idx, created_at, updated_at
) VALUES (...)
ON CONFLICT(code) DO UPDATE SET
  kind = excluded.kind,
  name = excluded.name,
  description = excluded.description,
  order_idx = excluded.order_idx,
  updated_at = excluded.updated_at;
```

주의: 관리자가 바꿀 수 있는 `allow_user_write`, `allow_comment`, `is_active`까지 매 부팅마다 덮어쓰면 안 된다. 최초 seed 때만 기본값을 넣고, 이후에는 이름/설명/정렬처럼 기본 노출에 필요한 값만 갱신한다.
