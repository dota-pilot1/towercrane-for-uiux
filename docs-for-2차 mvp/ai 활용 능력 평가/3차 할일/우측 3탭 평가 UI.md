# 3차 — 우측 3탭 평가 UI

## 탭 구조

```
┌──────────────────────────────────────────────────────┐
│  홍길동  풀스택 개발자                               │
│  ────────────────────────────────────────────────    │
│  [기술 역량 85/100]  [협업 역량 70/100]  [업무 생산성 90/100]  │
├──────────────────────────────────────────────────────┤
│  + 항목 추가                                         │
│                                                      │
│  NO  항목명              점수(0~10)   메모           │
│  ─────────────────────────────────────────────────   │
│  1   아키텍처 설계 능력  [  8  ]      [___________]  │
│  2   문제 해결 능력      [  7  ]      [___________]  │
│  3   API 설계 이해도     [  9  ]      [___________]  │
│  ...                                                 │
│                                                      │
│  소계: 85 / 100점                                    │
└──────────────────────────────────────────────────────┘
```

## 컴포넌트 구조

```
pages/ai-evaluation/ui/
  evaluatee-detail-panel.tsx      ← 우측 전체 패널
  eval-tab-panel.tsx              ← 탭 하나 (카테고리별 항목 목록)
  eval-item-row.tsx               ← 항목 행 (제목 + 점수 입력 + 메모 + 삭제)
  eval-item-add-dialog.tsx        ← 항목 추가 다이얼로그
```

## 항목 추가 다이얼로그 필드

- 항목명 (필수, 예: "아키텍처 설계 능력")
- 설명 (선택)

카테고리는 현재 탭이 자동으로 세팅.

## 점수 입력 방식

- `<input type="number" min="0" max="10">` — 직접 타이핑
- 포커스 아웃(blur) 시 자동 저장 (PUT /api/eval-items/:id/score)
- 저장 성공 시 토스트 없이 조용히 처리 (UX 노이즈 최소화)
- 범위 초과 입력 시 클램프 (0 미만 → 0, 10 초과 → 10)

## 탭 헤더 점수 표시

각 탭 레이블에 현재 소계 실시간 반영:
```
기술 역량 (85/100)   협업 역량 (70/100)   업무 생산성 (90/100)
```

## 스타일 규칙

- raw 팔레트 금지, semantic token 사용
- 탭 액티브: `border-brand-border text-brand-primary`
- 항목 행 hover: `bg-surface-muted`
- 점수 입력: `ui-input` 유틸 + `w-16 text-center`
