# 4차 — 총점 집계 + 레이더차트 시각화

## 상단 요약 카드 (유저 선택 시 우측 상단에 고정)

```
┌────────────────────────────────────────────────────┐
│  홍길동                              총점 245/300  │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐         │
│  │ 기술 역량 │  │ 협업 역량 │  │ 업무 생산성│        │
│  │  85/100  │  │  70/100  │  │  90/100  │         │
│  └──────────┘  └──────────┘  └──────────┘         │
└────────────────────────────────────────────────────┘
```

## 레이더차트

라이브러리: `recharts` (이미 프로젝트에 있으면 재사용, 없으면 추가)
3개 축: 기술 역량 / 협업 역량 / 업무 생산성
값: 각 카테고리 합산 점수 (0~100)

```
컴포넌트: eval-radar-chart.tsx
위치: 요약 카드 우측 or 별도 탭 "종합"
```

## "종합" 4번째 탭 (선택 사항)

3탭 옆에 "종합" 탭 추가:
- 레이더차트
- 카테고리별 점수 바 차트
- 전체 항목 텍스트 요약

## API 연동

`GET /api/evaluatees/:id/summary` 응답 구조:
```json
{
  "totalScore": 245,
  "maxScore": 300,
  "categories": [
    { "id": "cat_tech",   "name": "기술 역량",   "score": 85, "maxScore": 100 },
    { "id": "cat_collab", "name": "협업 역량",   "score": 70, "maxScore": 100 },
    { "id": "cat_prod",   "name": "업무 생산성", "score": 90, "maxScore": 100 }
  ]
}
```

## 스타일

- 요약 카드 3개: `ui-panel-soft` + 카테고리별 브랜드 컬러 포인트
- 총점 강조: `text-brand-primary text-2xl font-bold`
- 레이더차트 fill: `var(--brand-primary)` opacity 20%
