# 2차 — 좌측 유저 목록 패널

## 레이아웃 (게시판 참고, 더 넓게)

```
┌─────────────────────────────────────────────────────────────┐
│  AI 활용 능력 평가                          + 대상자 추가   │
├──────────────────────┬──────────────────────────────────────┤
│  [검색창]            │                                      │
│  ─────────────────   │   (우측: 2차에서 빈 상태 안내)      │
│  ● 홍길동  풀스택    │                                      │
│  ● 김철수  프론트    │                                      │
│  ● 이영희  백엔드    │                                      │
│                      │                                      │
└──────────────────────┴──────────────────────────────────────┘

비율: 좌 28% / 우 72%   (게시판은 35/65)
```

## 컴포넌트 구조

```
pages/ai-evaluation/ui/
  ai-evaluation-page.tsx        ← 이미 생성된 stub 교체
  evaluatee-list-panel.tsx      ← 좌측 패널
  evaluatee-add-dialog.tsx      ← 대상자 등록 다이얼로그
  evaluatee-list-item.tsx       ← 목록 행 (이름 + 역할 + 액티브 스타일)
```

## 대상자 추가 다이얼로그 필드

- 이름 (필수)
- 역할/직책 (예: 풀스택, 프론트엔드, 백엔드, AI 엔지니어)
- 한줄 소개 (선택)

## 유저 목록 행 디자인

```
● 홍길동
  풀스택 개발자
  총 0 / 300점
```

- 선택 시 `ui-panel` 액티브 스타일 (`border-brand-border bg-brand-glass`)
- 삭제는 hover 시 우측에 휴지통 아이콘 표시

## 상태 관리

- `selectedEvaluateeId` — useState로 로컬 관리
- 서버 데이터 — React Query (`useEvaluatees`, `useCreateEvaluatee`, `useDeleteEvaluatee`)

## 빈 상태

대상자 0명일 때 좌측에 "아직 등록된 대상자가 없습니다. + 대상자 추가" 안내.
선택 전 우측은 "대상자를 선택하세요." 플레이스홀더.
