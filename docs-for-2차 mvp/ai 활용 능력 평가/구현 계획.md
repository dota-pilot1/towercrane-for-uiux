# AI 활용 능력 평가 — 전체 구현 계획

## 개요

개발자의 AI 활용 역량을 3개 축으로 셀프 평가하는 페이지.
게시판 마스터-디테일 레이아웃 기반, 오른쪽 패널을 3탭으로 확장.

## 평가 구조

| 카테고리 | 항목 수 | 만점 |
|---|---|---|
| 기술 역량 | 10개 | 100점 |
| 협업 역량 | 10개 | 100점 |
| 업무 생산성 | 10개 | 100점 |
| **합계** | **30개** | **300점** |

항목당 0~10점, 스스로 점수 입력.

## 단계별 구현

| 단계 | 내용 |
|---|---|
| 1차 | DB 스키마 + 백엔드 API |
| 2차 | 좌측 유저 목록 패널 |
| 3차 | 우측 3탭 평가 UI (항목 추가 + 점수 입력) |
| 4차 | 총점 집계 / 레이더차트 시각화 |
