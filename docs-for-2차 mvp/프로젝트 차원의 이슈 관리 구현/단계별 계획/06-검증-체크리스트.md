- 프로젝트 이슈 API가 `issues` 테이블을 건드리지 않는다.

## 프론트엔드 검증

작업 디렉터리:

- `/Users/terecal/towercrane-for-uiux/towercrane-for-uiux-front`

명령:

```bash
pnpm typecheck
pnpm lint
pnpm build
```

브라우저 확인:

- `/project-issues?projectId={id}`가 열린다.
- 프로젝트 이슈에서 새 이슈를 만들 수 있다.
- 테이블/칸반/카드 뷰를 전환할 수 있다.
- 칸반 드래그로 상태가 바뀐다.
- 상세 다이얼로그에서 개요/체크리스트/첨부/댓글/활동 탭이 동작한다.
- 보관/복원 후 목록과 카운트가 갱신된다.
- 검색/유형/우선순위/담당자/정렬 필터가 동작한다.
- 기존 `/issues?prototypeId={id}` 프로토타입 이슈 화면이 그대로 열린다.
