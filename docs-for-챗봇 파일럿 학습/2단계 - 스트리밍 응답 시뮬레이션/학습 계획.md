# 2단계 — 스트리밍 응답 시뮬레이션

## 학습 목표

AI 응답이 글자 단위로 흘러나오는 스트리밍 패턴을 손에 익힌다.  
이 패턴은 실제 Claude API / OpenAI API의 `stream: true` 동작과 동일하다.

---

## 1단계와의 차이점

| | 1단계 (기본 채팅) | 2단계 (스트리밍) |
|---|---|---|
| 응답 방식 | 딜레이 후 한 번에 | 글자 단위로 누적 |
| `setMessages` 패턴 | `[...prev, newMsg]` 추가만 | `prev.map`으로 기존 메시지 **수정** |
| 로딩 표시 | 점 3개 인디케이터 (별도 UI) | 커서 깜빡임 (메시지 안에 포함) |
| Message 타입 | `role, content, timestamp` | + `isStreaming` 플래그 추가 |

---

## 핵심 개념

### 1. Message 타입에 isStreaming 추가
```tsx
type Message = {
  id: string
  role: 'user' | 'assistant'
  content: string
  isStreaming?: boolean   // ← 응답 중인지 표시
}
```

### 2. 메시지를 수정하는 setMessages 패턴
```tsx
// 1단계 — 추가만
setMessages(prev => [...prev, newMsg])

// 2단계 — 특정 id의 메시지를 찾아서 수정
setMessages(prev =>
  prev.map(m => m.id === msgId ? { ...m, content: chunk } : m)
)
```
- 응답 메시지를 미리 빈 내용으로 배열에 추가해두고
- 글자가 올 때마다 그 메시지만 업데이트하는 방식

### 3. simulateStream — 스트리밍 시뮬레이션
```tsx
function simulateStream(fullText: string, msgId: string) {
  let charIndex = 0
  setIsStreaming(true)

  streamIntervalRef.current = setInterval(() => {
    charIndex += Math.floor(Math.random() * 3) + 1   // 랜덤 청크 크기
    const chunk = fullText.slice(0, charIndex)        // 앞에서부터 누적

    setMessages(prev =>
      prev.map(m => m.id === msgId
        ? { ...m, content: chunk, isStreaming: charIndex < fullText.length }
        : m
      )
    )

    if (charIndex >= fullText.length) {
      clearInterval(streamIntervalRef.current!)
      setIsStreaming(false)
    }
  }, 30)   // 30ms마다 갱신
}
```

### 4. streamIntervalRef — interval을 ref로 관리하는 이유
```tsx
const streamIntervalRef = useRef<ReturnType<typeof setInterval> | null>(null)
```
- `setInterval` ID를 변수에 그냥 담으면 렌더링마다 사라진다
- `useRef`에 담으면 렌더링과 무관하게 유지되어 `clearInterval`로 정확히 정리 가능
- 컴포넌트가 언마운트되거나 전송이 중단될 때 정리하지 않으면 메모리 누수 발생

### 5. 커서 깜빡임 UI
```tsx
{msg.isStreaming && (
  <span className="ml-0.5 inline-block h-4 w-0.5 animate-pulse bg-brand-primary align-middle" />
)}
```
- `isStreaming`이 true인 동안만 커서를 메시지 끝에 표시
- `animate-pulse` — Tailwind 깜빡임 애니메이션

---

## 실제 Claude API 연결 시 달라지는 부분

```
지금 (시뮬레이션)          →  실제 API 연동 시
setInterval로 글자 쪼개기  →  ReadableStream.getReader()
slice(0, charIndex)         →  TextDecoder로 청크 디코딩
simulateStream()            →  fetch + stream 읽기 루프
```

프론트 `setMessages` 패턴은 동일 — API 연동해도 이 코드만 알면 바로 적용 가능
