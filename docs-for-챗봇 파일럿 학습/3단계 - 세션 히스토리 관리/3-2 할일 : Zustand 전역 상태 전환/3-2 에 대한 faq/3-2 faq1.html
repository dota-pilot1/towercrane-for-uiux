4. Date 직렬화 문제 — partialize + onRehydrateStorage

문제: localStorage는 JSON만 저장할 수 있다.
Date 객체를 저장하면 ISO 문자열로 변환되고,
복원 시 그냥 문자열 상태로 돌아온다.

→ message.timestamp.toLocaleTimeString() 호출 시 에러 발생 
{
  // 저장 시: Date → ISO 문자열로 직렬화
  partialize: (state) => ({
    sessions: state.sessions.map((s) => ({
      ...s,
      createdAt: s.createdAt instanceof Date ? s.createdAt.toISOString() : s.createdAt,
      messages: s.messages.map((m) => ({
        ...m,
        timestamp: m.timestamp instanceof Date ? m.timestamp.toISOString() : m.timestamp,
      })),
    })),
    activeId: state.activeId,
  }),

  // 복원 시: ISO 문자열 → Date 객체로 역직렬화
  onRehydrateStorage: () => (state) => {
    if (!state) return
    state.sessions = state.sessions.map((s) => ({
      ...s,
      createdAt: new Date(s.createdAt),
      messages: s.messages.map((m) => ({
        ...m,
        timestamp: new Date(m.timestamp),
      })),
    }))
  },
}
partialize — 저장할 때 어떤 형태로 직렬화할지
onRehydrateStorage — 불러올 때 어떻게 복원할지

저장: Date → 문자열 / 복원: 문자열 → Date
