# 3단계 — 세션 히스토리 관리

## 학습 목표

"새 대화" 버튼으로 대화를 여러 개 만들고,  
사이드바에서 이전 대화를 클릭해 불러오는 히스토리 패턴을 손에 익힌다.  
이 패턴은 ChatGPT / Claude 같은 실제 AI 챗봇 앱의 핵심 구조다.

---

## 2단계와의 차이점

| | 2단계 (스트리밍) | 3단계 (히스토리) |
|---|---|---|
| 대화 수 | 1개 (고정) | 여러 개 (동적 생성) |
| 상태 구조 | `messages[]` | `sessions[]` + `activeSessionId` |
| 새 대화 | 없음 | 버튼 클릭 → 새 세션 생성 |
| 이전 대화 | 없음 | 사이드바 클릭 → 세션 전환 |

---

## 핵심 개념

### 1. 세션(Session) 타입

```ts
type Session = {
  id: string
  title: string          // 첫 메시지로 자동 생성
  messages: Message[]
  createdAt: Date
}
```

메시지 배열 하나가 "대화 한 편"이다.  
세션은 그 대화 한 편을 감싸는 껍데기.

### 2. 상태 구조

```ts
const [sessions, setSessions] = useState<Session[]>([])
const [activeSessionId, setActiveSessionId] = useState<string | null>(null)
```

- `sessions` — 모든 대화 목록
- `activeSessionId` — 지금 화면에 보이는 대화가 어느 것인지

### 3. 현재 활성 세션 꺼내기

```ts
const activeSession = sessions.find(s => s.id === activeSessionId)
const messages = activeSession?.messages ?? []
```

`activeSessionId`로 `sessions` 배열에서 현재 대화를 찾아 메시지를 꺼낸다.

### 4. 새 대화 만들기

```ts
function createNewSession() {
  const newSession: Session = {
    id: Date.now().toString(),
    title: '새 대화',
    messages: [],
    createdAt: new Date(),
  }
  setSessions(prev => [newSession, ...prev])  // 목록 맨 위에 추가
  setActiveSessionId(newSession.id)           // 새 대화로 전환
}
```

### 5. 메시지 추가 — 세션 안으로 타겟팅

```ts
// 2단계: 그냥 추가
setMessages(prev => [...prev, newMsg])

// 3단계: 활성 세션의 messages 안에 추가
setSessions(prev =>
  prev.map(s =>
    s.id === activeSessionId
      ? { ...s, messages: [...s.messages, newMsg] }
      : s
  )
)
```

2단계의 `setMessages` 패턴이 `setSessions` 안으로 한 겹 들어간 것.  
구조만 달라졌을 뿐 개념은 동일하다.

### 6. 세션 제목 자동 생성

```ts
// 첫 메시지 전송 시 세션 제목을 첫 메시지로 설정
if (messages.length === 0) {
  setSessions(prev =>
    prev.map(s =>
      s.id === activeSessionId
        ? { ...s, title: text.slice(0, 20) }  // 첫 20자
        : s
    )
  )
}
```

---

## 2단계 코드와의 관계

```
2단계                          3단계
─────────────────────────────────────────────
messages[]                 →  sessions[].messages[]
setMessages(prev => ...)   →  setSessions(prev => prev.map(s => s.id === activeId ? ...))
(세션 개념 없음)            →  activeSessionId로 현재 대화 특정
```

2단계에서 익힌 `prev.map()` 패턴이 그대로 쓰인다.  
달라진 건 "메시지 하나 수정" → "세션 안의 메시지 배열 수정"으로 한 겹 깊어진 것.
