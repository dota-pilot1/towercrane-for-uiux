3-3 — 메시지 관련 주요 함수 정리

toMessage · map에 함수 참조 넘기기 · DTO 변환 패턴

1. dtos.map(toMessage) — 이게 뭔가?

📌 핵심

dtos.map(toMessage) 는 함수 참조(function reference) 패턴이다.

map에 화살표 함수 대신 함수 이름 자체를 넘기는 것.
아래 두 줄은 완전히 같은 동작이다. 
// 1) 화살표 함수로 감싸는 방식 (풀어쓴 버전)
const messages = dtos.map((m) => toMessage(m))

// 2) 함수 참조 방식 (지금 코드)
const messages = dtos.map(toMessage)
map은 배열 원소 하나를 받아서 뭔가를 반환하는 함수를 기대한다.
toMessage 자체가 "원소 하나 받아서 변환된 객체 반환" 이니까
그냥 이름만 넘겨도 된다. 결과는 동일하다.

2. map이 하는 일

dtos = [
  { id: '1', role: 'user',      content: '안녕',  createdAt: '2026-05-24T...' },
  { id: '2', role: 'assistant', content: '안녕!', createdAt: '2026-05-24T...' },
]

       ↓ dtos.map(toMessage)

       원소 1개씩 toMessage에 들어감
       ┌──────────────────────────────────────────────────┐
       │ toMessage({ id: '1', ..., createdAt: '...' })    │ → { id: '1', ..., timestamp: Date }
       │ toMessage({ id: '2', ..., createdAt: '...' })    │ → { id: '2', ..., timestamp: Date }
       └──────────────────────────────────────────────────┘

messages = [
  { id: '1', role: 'user',      content: '안녕',  timestamp: Date객체 },
  { id: '2', role: 'assistant', content: '안녕!', timestamp: Date객체 },
]
원소 2개 들어가서 → 변환된 원소 2개 나온다.
배열 길이는 그대로, 안의 내용만 바뀐다.

3. toMessage 함수 — 실제 코드

// chat-session-store.ts  36번째 줄
function toMessage(m: MessageDto): Message {
  return {
    id: m.id,
    role: m.role,
    content: m.content,
    timestamp: new Date(m.createdAt),   ← 핵심 변환
  }
}

이 함수가 하는 일 3가지

변환전 (DB/API)후 (store)
타입 변환 createdAt: string
'2026-05-24T05:18:13.000Z'		 timestamp: Date
new Date('2026-05-24T...')
이름 변환 createdAt timestamp
sessionId 제거 sessionId: 'abc-...' 있음 없음 — store에서 불필요
왜 이름이 바뀌는가?
DB 쪽은 createdAt (생성 시각)이라는 의미.
프론트 store는 timestamp (표시용 시각)이라는 이름으로 통일해서 쓰기 때문.

4. 함수 참조 패턴 — 왜 쓰나

// 화살표 함수 버전
dtos.map((m) => toMessage(m))

// 함수 참조 버전
dtos.map(toMessage)
화살표 함수 버전함수 참조 버전
동작완전히 같음완전히 같음
코드 길이길다짧다
언제 쓰나인자를 가공할 때
(m) => toMessage(m.data)		인자를 그대로 넘길 때
인자를 그대로 넘길 때는 함수 참조가 더 깔끔하다.
dtos.map(m => toMessage(m)) 에서 m 은 받자마자 그냥 넘기는 것뿐.
이럴 때 dtos.map(toMessage) 로 줄이는 게 일반적인 관행이다.

5. 같은 패턴 — toSession도 동일

// loadSessions() 내부
const dtos = await apiRequest<SessionDto[]>('/chatbot/sessions')
const sessions = dtos.map(toSession)   ← toMessage 와 완전히 같은 패턴
// toSession 함수 (27번째 줄)
function toSession(s: SessionDto): Session {
  return {
    id: s.id,
    title: s.title,
    createdAt: new Date(s.createdAt),
    updatedAt: new Date(s.updatedAt),
  }
}
toSession 도 ISO string → Date 변환이 핵심.
세션은 날짜가 2개(createdAt, updatedAt)라서 두 줄 변환.

6. 정리

dtos.map(toMessage) 한 줄에 담긴 의미:

① map — 배열 원소마다 함수 1번씩 실행
② toMessage — 함수 이름을 직접 넘기는 함수 참조 패턴
③ 변환 결과 — ISO string이 Date 객체로 바뀐 새 배열
