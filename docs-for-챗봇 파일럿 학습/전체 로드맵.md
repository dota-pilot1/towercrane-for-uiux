# 챗봇 파일럿 학습 로드맵

7월 업무(AI 챗봇 개발, React 코드 최적화) 대비 단계별 실습.  
각 단계는 하나의 핵심 개념을 집중 학습하고 실제 페이지에 구현한다.

---

## 전체 5단계

| 단계 | 핵심 개념 | 실습 페이지 | 경로 |
|---|---|---|---|
| 1단계 | useState 메시지 흐름 | 기본 채팅 | `/chatbot` |
| 2단계 | 스트리밍 응답 시뮬레이션 | 스트리밍 응답 | `/chatbot/streaming` |
| 3단계 | 세션 히스토리 관리 | 히스토리 관리 | `/chatbot/history` |
| 4단계 | React Flow 워크플로우 | React Flow | `/chatbot/flow` |
| 5단계 | 파일 첨부 UI | 파일 첨부 | `/chatbot/files` |

---

## 왜 이 순서인가

1. **상태 관리 먼저** — 메시지 배열을 어떻게 다루는지 이해하면 나머지가 쉬워진다
2. **스트리밍** — 실제 AI API의 핵심 패턴. 이것만 알아도 Claude API 바로 연동 가능
3. **히스토리** — 세션 개념을 붙이면 진짜 챗봇 앱 구조가 된다
4. **React Flow** — AI 서비스 관리/모니터링 화면에 직접 쓰일 기술
5. **파일 첨부** — 문서 기반 AI 서비스에 필수 (RAG 연동 전 UI 레이어)
