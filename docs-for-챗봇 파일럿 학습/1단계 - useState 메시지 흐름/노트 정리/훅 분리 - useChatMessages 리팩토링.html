훅 분리 — useChatMessages 리팩토링

1단계 노트 · FSD model 레이어에 커스텀 훅 분리하기

왜 분리했나

원래 ChatbotBasicPage 컴포넌트 안에
"UI를 어떻게 보여줄까" 와 "메시지 상태를 어떻게 관리할까" 가 한 덩어리였다.

페이지가 하나일 땐 괜찮지만, 챗봇 페이지가 여러 개가 되면
비슷한 상태 로직이 각 파일마다 복붙되기 시작한다.
훅으로 뽑아두면 로직은 한 곳에 모이고, 페이지는 JSX만 남는다.

1. 파일 구조 변화

// 리팩토링 전
pages/chatbot/ui/chatbot-basic-page.tsx
  └─ Message 타입
  └─ MOCK_RESPONSES 상수
  └─ useState, useRef, useEffect (상태 로직)
  └─ handleSend, handleKeyDown (이벤트 핸들러)
  └─ return <JSX>

// 리팩토링 후
features/chatbot/model/use-chat-messages.ts   ← 로직
  └─ Message 타입
  └─ MOCK_RESPONSES 상수
  └─ useChatMessages() 훅

pages/chatbot/ui/chatbot-basic-page.tsx          ← UI만
  └─ useChatMessages() 호출
  └─ return <JSX>

2. 커스텀 훅의 구조

// features/chatbot/model/use-chat-messages.ts
export function useChatMessages() {
  const [messages, setMessages] = useState<Message[]>([...]);
  const [input, setInput] = useState("");
  const [isTyping, setIsTyping] = useState(false);
  const bottomRef = useRef<HTMLDivElement>(null);

  useEffect(() => { bottomRef.current?.scrollIntoView(...) }, [...]);

  function handleSend() { /* mock 응답 생성 */ }
  function handleKeyDown() { /* Enter 키 처리 */ }

  // 페이지가 필요한 것들만 return
  return { messages, input, setInput, isTyping, bottomRef, handleSend, handleKeyDown };
}
커스텀 훅은 결국 return 값이 있는 함수다.
useState · useRef · useEffect 를 안에서 쓸 수 있는 이유는
이름이 use로 시작하기 때문이다 (React 훅 규칙).

3. 페이지가 훅을 쓰는 방법

// pages/chatbot/ui/chatbot-basic-page.tsx
import { useChatMessages } from "../../../features/chatbot/model/use-chat-messages";

export function ChatbotBasicPage() {
  const { messages, input, setInput, isTyping, bottomRef, handleSend, handleKeyDown }
    = useChatMessages();

  return (
    <!-- JSX만 -->
  );
}

페이지 입장에서는 "훅에서 필요한 값들을 꺼내 쓴다" 는 것만 알면 된다.
내부에서 어떻게 상태를 관리하는지는 훅 파일만 보면 된다.

4. FSD에서 어느 레이어에 두나

레이어 역할 이번 예시
pages 화면 조합 (JSX) chatbot-basic-page.tsx
features 사용자 행동 단위 로직 useChatMessages 훅
entities 도메인 타입 · API (지금은 훅 안에 같이 있음)
features/chatbot/model/ 의 model 폴더는
"이 feature의 상태와 비즈니스 로직"을 담는 곳이다.
UI가 없으면 model/, UI가 있으면 ui/ 에 넣는다.

5. 한 줄 요약

훅 분리 = "로직을 페이지 밖으로 꺼내서 재사용 가능하게 만들기"

페이지  →  어떻게 보여줄까  (JSX)
훅     →  상태를 어떻게 관리할까  (useState / useEffect / 핸들러)
