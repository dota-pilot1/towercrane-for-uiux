사용자 메시지는 오른쪽, 챗봇은 왼쪽인 이유

1단계 노트 · flex-row-reverse 동작 원리

먼저 실제 화면 확인

안녕하세요! 무엇을 도와드릴까요?
👤
안녕하세요!

좋은 질문입니다!

1. 핵심 코드 한 줄

// chatbot-basic-page.tsx 99번째 줄
<div className={`flex gap-3 ${msg.role === "user" ? "flex-row-reverse" : ""}`}>
role이 "user" 이면 → flex-row-reverse 추가
role이 "assistant" 이면 → 아무것도 추가 안 함 (기본 flex = 왼쪽부터)

2. flex-row-reverse 가 하는 일

flex 컨테이너 안의 자식들을 오른쪽에서 왼쪽 방향으로 배치한다.

챗봇 메시지 — flex 기본값 (row)

아바타
말풍선

사용자 메시지 — flex-row-reverse

아바타
말풍선
코드 순서는 [아바타 → 말풍선] 으로 똑같다.
flex-row-reverse 하나로 시각적 위치만 뒤집는다.
조건에 따라 클래스 하나만 추가/제거하면 되니까 코드가 단순해진다.

3. 말풍선 색상도 role로 분기

<div className={`... ${msg.role === "user"
  ? "bg-brand-glass border-brand-border text-brand-primary"
  : "bg-surface-raised border-surface-border-soft ui-text-primary"
}`}>
user → 초록 배경 + 초록 텍스트 (브랜드 색)
assistant → 회색 배경 + 기본 텍스트

4. 아바타 아이콘도 role로 분기

{msg.role === "assistant"
  ? <Bot className="size-4 text-brand-primary" />
  : <User className="size-4 ui-text-secondary" />
}

5. 결론 — msg.role 하나로 세 가지를 동시에 제어

① 좌우 위치 → flex-row-reverse
② 말풍선 색상 → bg-brand-glass vs bg-surface-raised
③ 아바타 아이콘 → Bot vs User 
// 메시지 하나를 그릴 때 전체 구조
<div className={`flex gap-3 ${role === "user" ? "flex-row-reverse" : ""}`}>

  <div> ← 아바타
    {role === "assistant" ? <Bot /> : <User />}
  </div>

  <div className={role === "user" ? "초록색" : "회색"}>
    {msg.content} ← 말풍선
  </div>

</div>
