# 1단계 — useState 메시지 흐름

## 학습 목표

메시지를 배열로 관리하고, 사용자 입력 → 상태 업데이트 → 화면 반영 흐름을 손에 익힌다.

---

## 핵심 개념

### 1. 메시지 배열 상태
```tsx
type Message = {
  id: string
  role: 'user' | 'assistant'
  content: string
  timestamp: Date
}

const [messages, setMessages] = useState<Message[]>([])
```
- 메시지는 배열로 관리 — 새 메시지는 `[...prev, newMsg]` 패턴으로 추가
- `id`는 `Date.now().toString()` 으로 임시 생성 (실제 API는 서버가 부여)
- `role`로 내 메시지와 AI 메시지를 구분

### 2. 불변 업데이트 패턴
```tsx
// ✅ 올바른 방법 — 새 배열 반환
setMessages(prev => [...prev, newMsg])

// ❌ 잘못된 방법 — 직접 변경
messages.push(newMsg)
setMessages(messages)
```

### 3. 로딩 상태 분리
```tsx
const [isTyping, setIsTyping] = useState(false)
```
- 전송 후 → `isTyping = true` → 응답 도착 → `isTyping = false`
- 타이핑 인디케이터(점 3개 애니메이션)를 별도 UI로 표시

### 4. 자동 스크롤
```tsx
const bottomRef = useRef<HTMLDivElement>(null)

useEffect(() => {
  bottomRef.current?.scrollIntoView({ behavior: 'smooth' })
}, [messages, isTyping])   // 메시지나 타이핑 상태가 바뀔 때마다 스크롤
```

### 5. Enter 키 전송
```tsx
function handleKeyDown(e: React.KeyboardEvent<HTMLTextAreaElement>) {
  if (e.key === 'Enter' && !e.shiftKey) {
    e.preventDefault()   // textarea 기본 줄바꿈 방지
    handleSend()
  }
}
```

## 체크리스트

- [ ] 메시지 전송하면 내 말풍선이 오른쪽에 뜨는가
- [ ] AI 응답이 왼쪽에 뜨는가
- [ ] 전송 중 점 3개 타이핑 인디케이터가 뜨는가
- [ ] 새 메시지가 오면 자동 스크롤 되는가
- [ ] Enter로 전송, Shift+Enter로 줄바꿈 되는가
- [ ] 빈 메시지는 전송되지 않는가
