# 현재 작업중인 파일 내역

---

## 업무 관리 (Task 페이지)

### 진입점
| 파일 | 역할 |
|---|---|
| `pages/task/ui/task-page.tsx` | 페이지 루트. 뷰 모드 전환(테이블/칸반/카드), 필터, 페이지네이션, CRUD 총괄 |

### API / 타입
| 파일 | 역할 |
|---|---|
| `entities/task/model/types.ts` | Task, TaskStatus, TaskPriority, TaskType 등 타입 정의 |
| `entities/task/model/constants.ts` | 상태·우선순위·유형 라벨, 배지 스타일 상수 |
| `entities/task/api/task-api.ts` | 모든 task REST API 호출 함수 모음 |
| `features/task/model/use-task-queries.ts` | React Query 훅 전체 (`useTasks`, `useCreateTask`, `useUpdateTask` 등) |

### UI 컴포넌트 (`features/task/ui/`)
| 파일 | 역할 |
|---|---|
| `task-toolbar.tsx` | 검색·필터(유형/상태/우선순위/담당자)·정렬·아카이브 토글·뷰 전환 툴바 |
| `task-table-view.tsx` | 테이블 뷰 (드래그 정렬, 행 선택) |
| `task-kanban-view.tsx` | 칸반 뷰 (상태별 컬럼, 드래그&드롭) |
| `task-card-view.tsx` | 카드 그리드 뷰 (드래그&드롭, 상태 그룹핑) |
| `task-card.tsx` | 개별 카드 컴포넌트 (제목·유형·상태·우선순위·마감일) |
| `task-badges.tsx` | 상태·우선순위·유형 배지 컴포넌트 |
| `task-form-dialog.tsx` | 업무 생성 다이얼로그 |
| `task-detail-dialog.tsx` | 업무 상세/편집 다이얼로그 (탭: 체크리스트/댓글/활동/첨부) |
| `task-checklist-panel.tsx` | 체크리스트 탭 패널 |
| `task-comments-panel.tsx` | 댓글 탭 패널 (Lexical 에디터) |
| `task-activity-panel.tsx` | 활동 로그 탭 패널 |
| `task-attachments-panel.tsx` | 파일 첨부 탭 패널 |

### 공통 컴포넌트 (관련)
| 파일 | 역할 |
|---|---|
| `shared/ui/switch.tsx` | 진행 업무 토글 스위치 (공통 컴포넌트) |
